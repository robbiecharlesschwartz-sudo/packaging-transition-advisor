# Fixed by hand

Every place where the pipeline or the AI output was wrong, and how it was corrected. This file feeds the case study.

| # | Phase | What went wrong | How it was caught | Fix |
|---|---|---|---|---|
| 1 | Corpus | 20 of 53 starting URLs failed (404 after site redesigns, 403 bot walls). | `fetch.py --check` report | Found current official locations for 13 (e.g. Colorado CDPHE moved to `/hm/epr-program`, Washington Ecology pages moved under `2021-plastic-pollution-laws/`). Seven sites block scripts (NJ DEP behind Incapsula, nysenate.gov, CA leginfo, ftc.gov case pages, Chicago, LA Sanitation); these are kept as `link_only` references with no text, and the bot protection was not bypassed. |
| 2 | Corpus | Minnesota statute page `115A.144` parsed to 32 words: the HTML is a navigation shell and the PDF of 115A.144 is only the short title. | `parse.py` LOW TEXT flag | Assembled the full Act by fetching each section PDF (115A.144 to 115A.1463) — 23 sections, 14,700 words (`fetch_special.py mn`). |
| 3 | Corpus | Oregon bottle-bill page (OLCC) and Minnesota PCA page returned only menus; the HTML fallback extractor admitted navigation text as content. | Read the extracted text | Replaced with the statute itself (ORS chapter 459A, which covers both the bottle bill and the Recycling Modernization Act) and the Minnesota statute. |
| 4 | Corpus | FDA recycled-plastics guidance page extracted to boilerplate only (the text sits in a downloadable PDF). | `chunk.py` "0 chunks after cleaning" | Pointed `fetch_url` at the guidance PDF (`/media/150792/download`). |
| 5 | Corpus | Amcor's 10-K produced 16 words: the item headings matched the table of contents, not the body. | `parse.py` LOW TEXT flag | 10-K item extraction now picks, for each item, the heading occurrence that starts the longest span. |
| 6 | Chunking | Chunks were sized at ~700 tokens, but `bge-small-en-v1.5` truncates at 512 tokens, so the tail of most chunks was never embedded. | Checked the model card while wiring ingest | Chunks capped at ~480 tokens (DECISIONS D10). Corpus went from 934 to 1,579 chunks before the corpus grew further. |
| 7 | Retrieval | "When do producer fees start under Oregon's packaging EPR program" ranked a Maine page first; the corpus had no fee schedule at all. | `scripts/ask.py` hand check | Added the CAA Oregon program plan, its 2026 amendment and the 2025 annual report (which contains the actual 2025 Oregon fee schedule, pp. 59–60). |
| 8 | Retrieval | "EPS food container ban" filtered to WA and NY returned federal documents only: the Washington page ingested was an overview that never describes the EPS ban, and New York is link-only. | `scripts/ask.py` hand check | Replaced with Ecology's dedicated EPS-ban page. New York remains a known gap (documented in the brief's evidence-gaps section when NY is selected). |
| 9 | Corpus | No open-access paper in the corpus states polymer densities in body text (searched every chunk for g/cm³). | Regex search over `chunks.jsonl` | Added a material-property reference document built from Wikipedia infobox/body excerpts (CC BY-SA, marked `secondary`), plus JATS table capture so tables in papers become chunks. |
| 10 | Prices | The Census International Trade API (import $/kg) started requiring an API key; the request was redirected to `missing_key.html`. | `fetch_special.py trade` failure | Switched to UN Comtrade's keyless public preview API, which republishes the same US Census import data (value and net weight per HS6 code); one request per month because the preview allows one period per call (DECISIONS D17). |
| 11 | Sourcing | Keyword rules over-tagged suppliers with materials they only mention as competitors (e.g. Crown tagged "glass", O-I tagged "aluminum"). | Read the tag output next to each filing's business description | Product lines are now a hand-reviewed spec of verbatim 10-K quotes (`build_suppliers.py`), each verified against a corpus chunk; the build fails if a quote is missing. |
| 12 | Infrastructure | D1's free 5M rows-read/day limit was exhausted in one afternoon: the FTS5 table stored `chunk_id` as an unindexed column, so every per-chunk `DELETE ... WHERE chunk_id = ?` scanned the whole index. | D1 error `exceeded D1's free tier daily row read limit` | FTS rows now share the chunks table's integer rowid (migration `0002_fts_rowid.sql`); corpus counts are cached in `meta` instead of `COUNT(*)` per request; local development uses a local D1 seeded from `chunks.jsonl`. |
| 13 | Verification | The verifier removed 24 of 60 correct claims in the first full brief: the number check treated citation markers like "[19]" and ISO date parts like "01" as unsupported numbers, and the LLM fact-checker never saw the cost calculator output, so every correct cost figure was "unsupported". | Read the removed-claims list | Strip citation markers before number checks; reduce ISO dates to the year; pass calculator / supplier-table output to the fact-checker as a deterministic "tool output" source; give the verifier the same passage length as the writer. Supported share went from 52% to 95%. |
| 14 | Corpus | The source list pointed the Keurig enforcement case at SEC press release 2024-118, which is an unrelated whistleblower case. | Eval pre-flight: expected answer text not found in the expected document | Corrected to 2024-122 ("SEC Charges Keurig with Making Inaccurate Statements Regarding Recyclability of K-Cup Beverage Pods"), re-fetched and re-embedded. |
| 15 | Generation | Gemini 2.5 models are retired for new projects (404) and the first key belonged to a prepaid project with no credit (402). | `/api/admin/gemini-probe` | Model ids are config with an ordered fallback list; 404/429 move to the next model; a free-tier key from a project with no billing is required (README > Setup). |
| 16 | Generation | Free-tier quota for the main Gemini model ran out mid-run and the write step stalled in retry loops. | Run stuck in "write" for 10+ minutes | Quota-aware routing: planning and verification use the lite model first; a model that returns 429 is skipped for 10 minutes; Workers AI is the last fallback. |
| 17 | Windows dev | `wrangler dev` and Vite failed inside the very long session path (Windows 260-character limit) with ENOENT and `SQLITE_CANTOPEN`. | Local dev server errors | Map a short drive letter with `subst`, persist local D1 state under a short real path, and preview the built app (`npm run preview:built`). Documented in README > Local development. |
| 18 | Report | Regulatory sections came out as "Evidence Gap" even though they held verified state-by-state rows: the report step treated "no narrative bullets" as "no evidence" and checked headline numbers only against bullet citations. | Read the regenerated examples before the case study | A section is a gap only when it has no bullets and no verified structured content; headline numbers are checked against all of the section's passages. |
